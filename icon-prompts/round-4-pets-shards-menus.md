# Round 4: Spirit Shards, menu buttons, ghost pets (and optional eggs / tower)

All: **512x512 PNG, square 1:1, transparent background is fine**, one subject centred (Roblox
may crop icons to a circle), **no text, no letters, no numbers**. Upload each as an Image and
send Claude the id + file name. Until then the game shows emoji, so nothing is blocked.

Paste this STYLE block first, then the line for one icon:

> Make a game icon for "Ghost Hunters Simulator", a cute spooky Roblox game. 512x512 PNG.
> Chunky rounded cartoon shapes, thick dark purple outline, glossy cel shading, bright candy
> colours with ghost-green ectoplasm accents, soft glow, friendly and cute (not scary). One
> subject centred, filling about 70% of the image, a few small sparkles. No text, no letters,
> no numbers.
